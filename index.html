Удерживай кнопку в левом верхнем углу 1,5 секунды. Когда полоска заполнится, приложение закроется.

02 / НАЧАТЬ ИГРУ

Установи. Дождись загрузки. Отправляйся в путь.

  1. Скачай APK на телефон и открой его из загрузок.
  2. Если Android попросит, разреши установку для приложения, которым открываешь файл.
  3. При первом запуске дождись распаковки ресурсов. Оставь несколько гигабайт свободного места.
  4. Выбери главу и играй в горизонтальном положении.

Обновление устанавливай поверх предыдущей версии — удаление приложения может стереть сохранения. Совместимость с другими моделями телефонов ещё не подтверждена.
